# Headway

Timetable site at headway.shivrajsinh.in (not live yet): Astro static pages, built from the data Stopwatch already generates.

## Commands

```bash
npm run sync      # pick the pages and copy their data from ~/transit-timetables
npm run build     # build dist/, then fail on any page that breaks the checks
npm run preview   # serve dist/ locally
```

`PAGES=200 npm run sync` raises the page count. Ramp it only once most published pages are indexed.

Run `sync` after every Stopwatch data refresh. `TRANSIT_DIR` points it at another checkout.

## What decides what

- `scripts/sync-data.mjs`: which pages exist, ranked by Search Console clicks, then impressions. Floors keep thin pages out.
- `src/data/site.json`, `public/data/`, `src/styles/routes.css`, `data/lastmod.json`: generated by sync. Don't edit them by hand.
- `scripts/verify-build.mjs`: titles, descriptions, canonicals, broken links, placeholders. A failure stops the release.
- `src/lib/route.js`: every sentence on a route page, computed from its timetable.
- `src/scripts/`: browser code. Every page reads correctly without it.

## Times

Timetable columns are by trip, and are the source of truth. Stop files list a stop's times with no trip ids, so they are matched to trips only between neighbouring timepoints. Where the two disagree at a direction's first stop, that direction offers its timepoints only rather than show partial times.

## Serving

Clean URLs need nginx to try `$uri.html`. `/404.html` is the not-found page.
